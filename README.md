# 光谱联合解算工作台

一个完全离线的网页应用：把多条虚构参考谱、混合谱、波长有效区与标定数据放进来，联合估计
**非负组分含量**与**受限基线**，并在参考谱近似共线时只报告可辨识的合计值。

所有数据都是程序生成的虚构合成数据，**不依赖任何外部仪器**。

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 27 个测试：数值核心 + 导入/历史 + 页面渲染
npm run build    # tsc -b && vite build
npx tsx scripts/sanity.ts   # 打印一整套恢复误差与选参路径
```

## 为什么不能直接求逆

直接最小二乘 `c = (SᵀS)⁻¹Sᵀy` 有两个问题，内置数据把两者都演示出来：

1. **基线漂移被吸收进组分**。参考谱本身有缓慢起伏时，组分项可以假装成基线，把浓度推高。
2. **近似共线的参考谱**。两个只差很小方向的参考谱，`SᵀS` 的条件数很大，反解出的系数一个
   大幅为正、一个大幅为负。负浓度在物理上无意义。

这里的做法是**联合**估计

```
minimize   Σ_i (y_i − Σ_j c_j·s_j(λ_i) − Σ_k β_k·B_k(λ_i))² / σ_i²
subject to c_j ≥ 0,  |β_k| ≤ bound
```

- 组分与基线在同一个箱式约束二次规划里求解（active-set），不再是交替迭代。
- 基线用 Chebyshev 多项式基，系数带上限；`λb` 是相对该坐标 Gram 对角元的岭正则。
- 可辨识性在**扣除基线后**、按噪声加权判：成对 |r| ≥ 0.995 或条件数 ≥ 20 的组分并成一组，
  组的列取成员谱的**均值**，因此该组的系数就是合计值。成员自身只标 `merged`，不给数值、
  不给区间。

## 内置数据的故事

| 项目 | 内容 |
| --- | --- |
| 波长 | 400–760 nm，步长 1 nm，361 点；默认有效区 412–748 nm |
| 噪声 | 异方差，每样 3 次重复测量，仅用于估噪声水平 |
| 标定库 2025.1 | A、B、C、D、E。**B 的参考谱混入大量 A**，与 A 近乎共线（成对 r ≈ 0.9995，整体 κ ≈ 71） |
| 标定库 2026.1 | B 换成高分辨复测（544 nm 特征带显现），新增候选 F；六个组分全部可单独辨识（κ ≈ 5.2） |
| 未建模污染 P | 505 / 736 nm 窄线，**不在任何参考库中**。与每个扣除基线后的参考谱 |r| < 0.2 |
| 局部坏点 | 若干样品的单通道尖峰（如 UN-01 的 574 / 713 nm） |
| 样品 | CAL-01…04 用于选参，VAL-01…03 有真值用于验证，UN-01/02 为未知样（其中 UN-01 含污染） |

因此同一份数据可以演示：换库 → 可辨识性重判 → A+B 从“只能合计”变成两个独立值，
而旧结果按旧库成对归档。

**每个组分谱相对三次基线的 R² 都 < 0.78**，所以组分不会被基线整体吸收。

## 结果怎么读

- **已辨识**：给出 `值 ± 95% 区间`。
- **只能合计**：只给组总计，区间写“只给合计，无区间”；没有各成员数值。
- **区间作废**：该组分主峰（或 > 55% 能量）被屏蔽，旧的 ± 值不再适用于新设置。
  屏蔽会改变历史签名的掩码部分，旧快照因此不会被当成当前结论。
- **未检出**：估计值被约束在 0。
- **不能解释的信号**：连续超过 3.2σ 的残差区间，以及孤立尖峰。尖峰的判据是残差偏离两侧隔两个通道的
  连线：`d = r[i] − (r[i−2] + r[i+2]) / 2`，要求 `|d| > 5σ_d`（`σ_d = √1.5·σ_i`）且 `|d| > 3×噪声RMS`，
  相邻 2 nm 内的命中合并为最强通道。平滑的污染线即使处于陡峭边缘也不会触发，所以一条宽污染线只形成
  未解释区间，而落在其肩部的尖峰仍能被单独指出。内置污染 P 的窄线正出现在这里，提示存在参考库以外的成分。

恢复误差核对面板把**可辨识合计值**与已知比例比较（合并组处合并真值），并给出基线漂移、基线拟合
偏差与污染指示幅度。真值默认隐藏，解算器从不读取它。

## 稀疏拟合

`稀疏（L1）` 模式在非负箱式 QP 之前做软阈值：阈值 = `λ₁ · 0.1 · G_jj · median(正的最小二乘系数)`,
因此 λ₁ 是无量纲的，且不受加权方式影响。在 CAL-03（不含 B、D）上可以看到 L1 路径把 B、D
压到恰好 0；加权模式忽略 λ₁。

两个正则参数都可以从**独立标定样**中挑：对候选 λ 网格逐点解算，用已知比例算组分误差，取均值最小者
（L1 在其近优带内取最稀疏的一个）。

## 页面结构

- 左栏：数据/样品、候选组分、波长窗口与屏蔽（也可在图上拖动圈选）、拟合设置、标定选参。
- 中栏：混合谱与联合拟合、残差、组分贡献、不能解释的信号、恢复误差核对。
- 右栏：可辨识性（含相关矩阵）、解算结果、历史结果、设计摘要。
- 底部：数据构成 / 求解算法 / 如何读结果 三页说明。

换样、换库或改设置后，旧快照会**保留**并标注“旧解算结果”，同时归档其当时的样本 + 参考库配对；
点击“按当前设置重新解算”才生成新结论。

## 导入格式

“导出数据”给出的 JSON 可再导入。必填字段：`wavelength`（递增）、`libraries[].references[].values`、
`samples[].values`（长度必须与 `wavelength` 一致）；`truth`、`replicates`（≥2 次才有意义）、
`contaminant`、`validRange` 可选。校验失败会显示具体原因，不会静默替换数据。

## 已知限制

- 浏览器自动化截图不能在当前容器内运行（缺系统库、无 root）；页面验证改由
  `tests/app.test.tsx` 在 happy-dom 中真实挂载 React 树、驱动指针圈选与重新解算。
- 污染幅度只能由残差投影给出**指示值**（低估值），不是精确回收——污染谱与其它组分部分重叠。
